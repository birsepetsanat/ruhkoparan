Ruhkoparan, gönüllülük ve yaratıcı iş birliği üzerine kuruludur.

Bu doğrultuda:

- ✍️ **Yazarlar**, hikâyenin ve evrenin gelişimine katkıda bulunur.
- 🎨 **Çizerler**, karakterleri, mekânları ve olayları görsel olarak hayata geçirir.
- 📝 **Editörler**, içeriklerin kalitesini ve tutarlılığını geliştirmeye yardımcı olur.
- 📋 **Koordinasyon ekibi**, görevlerin düzenli ilerlemesini ve ekipler arasındaki iletişimi destekler.

## 🏗️ Proje Yönetimi

Bu GitHub deposu, Ruhkoparan'ın üretim ve organizasyon süreçlerini yürütmek amacıyla kullanılmaktadır.

GitHub Issues ve Projects aracılığıyla görevler planlanır, ekipler arasında dağıtılır ve üretim süreçleri takip edilir.

### 📌 Genel İş Akışı

`Backlog → Todo → In Progress → In Review → Revision → Done`

| Durum | Açıklama |
|---|---|
| Backlog | Gelecekte değerlendirilmesi planlanan işler |
| Todo | Çalışmaya hazır görevler |
| In Progress | Üzerinde aktif olarak çalışılan görevler |
| In Review | İnceleme ve değerlendirme bekleyen çalışmalar |
| Revision | Düzenleme gerektiren çalışmalar |
| Done | Tamamlanan ve onaylanan görevler |
